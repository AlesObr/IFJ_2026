# Pomocné funkce a utility pro projekt IFJ26

V tomto adresáři se nachází pomocné funkce pro provoz repozitáře.

## `dstring.h/c`
Implementuje rozhraní pro správu a používání dynamického řetězce. Usnaďnuje práci s různě velkými řetězci bez nutnosti mít pevně stanovenou délku pole znaků, což by mohlo způsobovat problémy při načítání extrémně dlouhých řetězců. Primárně se bude hodit v lexeru.
